# College Ecosystem · Электронный журнал

Демонстрационный React-модуль единой системы **College Ecosystem**. Стек: React 19, TypeScript, Vite. Русскоязычный интерфейс, светлая бирюзовая палитра.

## Возможности демо

- Объединённый журнал оценок и посещаемости с выбором группы и дисциплины.
- Несколько оценок за занятие: 2, 3, 4, 5, З, НЗ.
- Отдельные отметки присутствия, отсутствия, уважительного пропуска и опоздания.
- Предварительная оценка: веса видов работ, необязательный зачёт/незачёт (З = 5, НЗ = 2), настраиваемый вес посещаемости.
- Источник оценки: ручная, автооценка из LMS, проверенная преподавателем в LMS.
- КТП и план/факт часов, предварительная аттестация, экспорт CSV (для Excel) и печать/сохранение в PDF браузером.
- Демо-импорт оценок из LMS с защитой от повторного добавления одной и той же записи.
- Локальное сохранение демонстрационных изменений в этом браузере.

> **Внимание:** это исключительно демонстрационный интерфейс с вымышленными студентами. Он НЕ подключён к Academic Core, NestJS, PostgreSQL, LMS, настоящим пользователям или официальному документообороту. Локальные изменения в браузере не являются юридически значимыми и не должны использоваться для реального учёта.

## Запуск

Нужен Node.js 22+.

~~~bash
npm install
npm run dev
npm run check
npm run build
~~~

## Публикация

Workflow в .github/workflows/deploy.yml выполняет проверку, сборку и публикацию через GitHub Pages. Репозиторий должен иметь право использовать Pages, а в Settings → Pages → Build and deployment источником должен быть выбран **GitHub Actions**. Для обычного GitHub Free публичный Pages требует публичного репозитория. Не публикуйте реальные данные студентов.

## Интеграция в общую экосистему

Демо-данные расположены в src/demo.ts, расчёты в src/calculations.ts, типы в src/types.ts. Следующий шаг — заменить демо-адаптер источником данных из существующих модулей NestJS, соблюдая общие Academic Core, TeachingAssignment, Lesson, Auth/RBAC и аудит. Не создавать копии Student/Group/Teacher и не считать расчётный итог официальной оценкой.

Официальные аттестации, фиксация правил на момент утверждения, PDF/Excel-документы установленного образца, версии и права утверждения потребуют серверной реализации, согласованной с моделью данных колледжа.
